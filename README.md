# Nicanor's Premium Portfolio

Create a premium, modern, fully responsive personal portfolio website for Nicanor Madziko, designed to impress recruiters, employers, and clients. The design should be elegant, minimal, and professional using a black (#0D0D0D), gold (#D4AF37), and white color palette with smooth animations, glassmorphism effects, subtle glowing accents, rounded cards, and soft shadows. Use a clean font such as Poppins or Inter.

The website should include the following pages and sections:

1. Home (Hero Section)
Display my name prominently: Nicanor Madziko. Below it, show the title: Python Developer | Django Developer | Product Designer | Digital Marketing Enthusiast. Include a short introduction: "I build modern web applications, user-centered digital products, and digital solutions that solve real-world problems." Add two call-to-action buttons: View My Projects and Download CV. Include a professional profile photo placeholder on the right with a subtle floating animation.

2. About Me
Create a clean section introducing who I am, my passion for software development, product design, digital marketing, and continuous learning. Add a modern timeline highlighting my learning journey.

3. Skills
Display skills as animated cards with progress bars grouped into categories:

 Programming: Python, Django, HTML, CSS, JavaScript

 Design: Figma, Canva, UI/UX Design, Product Design

 Marketing: Digital Marketing, Content Strategy, Prompt Engineering

 Tools: Git, GitHub, VS Code

4. Projects
Create beautiful project cards with image placeholders, project title, description, technologies used, GitHub button, and Live Demo button. Include placeholders for:

 Forex Trading Bot (MQL5)

 Django Web Application

 Product Design Case Study

 Portfolio Website

 Digital Marketing Campaign

5. Certifications
Create a modern certificate gallery with cards displaying certificate image placeholders, course name, issuing organization, completion date, and a "View Certificate" button. Include placeholders for:

 Python Certificate

 Product Design Certificate

 Fundamentals of Digital Marketing

 Future Certifications

6. Experience & Education
Display a vertical timeline for education, certifications, personal projects, internships, and freelance work.

7. Resume
Create a dedicated section with a professional summary and a prominent Download CV button.

8. Contact
Include a professional contact form and icons for Email, Phone, LinkedIn, GitHub, WhatsApp, and Location.

9. Footer
Include copyright information, quick navigation links, social media icons, and the text: Designed & Developed by Nicanor Madziko.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
